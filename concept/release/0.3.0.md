- **Hub** (`src/hub/`) : salon commun à tous les jeux à plusieurs, par WebSocket `/api/v1/hub` : prénom, chat général, salles par jeu, lancement par le propriétaire, ping.
- **Realm** : `GET /api/v1/realm` liste les serveurs (`serveur01`) et leurs jeux.
- Premier module de jeu : **bulles** (couleurs, +1 / −5, manches de 60 s). Contrat de module décrit dans `hub.js`.
- Classement `bulles_multi`. La CSP autorise le WebSocket du site. Dépendance `ws`.
- Détail et suite : `concept/multijoueur/architecture.md` du dépôt kassir_devops.
